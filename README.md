# Siva — Drone Photographer Portfolio

A fast, mobile-first portfolio website for **Siva**, a drone photographer and aerial cinematographer
based in **Gorakhpur, Uttar Pradesh, India** (Instagram / YouTube: `@gkp_drone`). It presents his aerial
films, stills, mapping and site-documentation work, the camera and drone kit behind them, and gives
clients one-tap ways to call, WhatsApp, email or follow him.

### What a visitor sees

1. **Landing (`/`)** — a full-screen aerial frame at golden hour with an *Explore* button that opens
   the full-screen menu.
2. **About, Experience, Projects, Skills, Education** — the story, the flight pipeline and numbers,
   four case studies (aerial film, mapping, kit management, progress documentation) with small working
   demos, capabilities and certificates, and a journey map of his training.
3. **Contact** — phone, WhatsApp, email, Instagram, Facebook, YouTube and a message form.
4. **Profile PDF** — a one-page CV generated by `scripts/build-resume.mjs`.

### How it is put together

```
src/app/          routes (one folder per page), layout, manifest, contact API route
src/components/   layout (header, menu, footer), sections per page, charts, dashboards, motion helpers
src/content/      ALL text and data: site.ts (contact + socials), projects.ts, skills.ts, ...
src/lib/          navigation and small utilities
public/           images (WebP/JPG), icons, resume PDF, sw.js (service worker), offline.html
scripts/          build-geo, build-resume, build-icons, and QA screenshot scripts
```

Editing the site is mostly editing files in `src/content/`: the pages read from there, so a phone
number or link changes in one place and updates the footer, the menu and the contact page.

### Performance and mobile choices

- Images are served as WebP through `next/image` at phone-sized widths; fonts are self-hosted.
- Mouse-only effects (custom cursor, inertial wheel scrolling) switch off on touch devices and for
  visitors who prefer reduced motion, so phones keep native scrolling.
- Scroll reveals use one `IntersectionObserver`; animation loops sleep when idle.
- The site is a PWA: installable on Android and usable offline (details below).

## Run locally

```bash
npm install
npm run dev          # http://localhost:3000
```

Production:

```bash
npm run build
npm start
```

Other scripts: `npm run lint`, `npm run typecheck`, `npm run generate:maps`
(recomputes the map geometry in `src/content/geo`), `node scripts/build-resume.mjs`
(rebuilds the one-page profile PDF from the text inside the script).

## Offline, installable and mobile

- `public/sw.js` is a service worker (registered in production only by
  `src/components/layout/ServiceWorker.tsx`). Pages are network-first with a 3 s cap, so a slow or
  missing connection falls back to the saved copy; scripts, fonts and images are served from the
  device cache. After the first visit it quietly saves every page and the image sizes that screen
  uses (skipped on Data Saver / 2G, at most once a day). `public/offline.html` is the fallback
  for a page that was never saved. Bump `V` in `sw.js` to force every device to drop its cache.
- `src/app/manifest.ts` + `public/icons/*` make the site installable on Android ("Add to Home
  screen"). Regenerate the icons with `node scripts/build-icons.mjs`.
- Mouse-only effects (smooth cursor, inertial wheel scrolling) are off on touch devices, which keep
  native momentum scrolling.

The contact *form* needs a connection to send through the email service; offline it opens the
visitor's mail app with a pre-filled draft, and the phone, WhatsApp and email links always work.

### Before launch: replace the placeholders

- `site.ts` — `NEXT_PUBLIC_SITE_URL` for metadata and social previews.
- `experience.ts`, `education.ts`, `credentials.ts` — company names, dates and certificate
  details are written as placeholders.

## Deploying

Any Node host works (`npm run build && npm start`); Vercel and Netlify's Next.js runtime both suit it.
Set `NEXT_PUBLIC_SITE_URL` to the live domain. To make the contact form send mail directly, set
`RESEND_API_KEY` and `CONTACT_TO_EMAIL`; without them the form opens the visitor's email app with a
pre-filled draft. The service worker only runs over HTTPS (or localhost).
